# Compliance Matrix

TrialVault is a prototype aligned to regulated clinical-trial controls. It is not HIPAA certified or FDA approved.

| Control Area | TrialVault Mechanism | Status |
| --- | --- | --- |
| PHI minimization | Patient-level data stored as encrypted values | Prototype |
| Consent evidence | Consent forms represented by hashes | Prototype |
| Access control | Patient-granted access levels and expiry | Prototype |
| Audit trail | Contract events for enrollment, outcome, aggregate compute, submission, audit | Prototype |
| Record integrity | Protocol hash, dataset hash, access log root, computation receipt | Prototype |
| Electronic signatures | Wallet signatures for actors | Planned |
| Regulator review | FDA audit dashboard without PII display | Prototype |
| Disclosure control | Aggregate-only researcher workflow | Prototype |
